# Learner Personas with Clustering

## Business Context
This project is based on the Data Career School Duolingo Learner Personas with Clustering challenge. The goal is to use unsupervised machine learning to discover meaningful learner behavior segments, convert them into actionable personas, and assign every learner to a cluster.

## Project Structure
- `data/`: Raw, processed, and final outputs
- `notebooks/`: Jupyter notebooks for exploration
- `src/`: Python source code modules
- `reports/`: Generated reports and visualizations
- `tests/`: Unit tests

## Instructions
Run `pip install -r requirements.txt` to install dependencies.
